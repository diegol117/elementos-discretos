MÓDULO 01 Proposiciones Lógicas: Definiciones

1.1 Proposiciones Simples

📌 Definición: Proposición Simple (o Atómica)

Es un enunciado declarativo que se representa con letras minúsculas $(p, q, r, \dots)$ y cumple tres condiciones:

  1. Es inequívocamente verdadera $(V)$ o falsa $(F)$.
  2. No contiene conectivos lógicos ni puede descomponerse en partes más simples.
  3. Su significado es preciso y objetivo.

En computación, asignamos letras minúsculas para facilitar su manipulación como instrucciones en código. Las expresiones exclamativas, interrogativas, imperativas o los enunciados abiertos no son proposiciones al carecer de un valor de verdad definido.

🧩 Ejemplo 1.1: Ejemplos de Enunciados y su Clasificación
  • «¡Qué hermoso día!»
    $\rightarrow$ No es proposición (exclamación).
  • «¿Ya terminaste el arreglo?»
    $\rightarrow$ No es proposición (interrogación).
  • «Limpia la base de datos.»
    $\rightarrow$ No es proposición (imperativo o mandato).
  • «$x + 5 = 10$»
    $\rightarrow$ No es proposición (enunciado abierto).
  • $p$: «El número 15 es divisible por 3.»
    $\rightarrow$ Proposición simple, valor lógico $V$.
  • $q$: «La capital de Francia es Madrid.»
    $\rightarrow$ Proposición simple, valor lógico $F$.
  • $s$: «El lenguaje Python es un lenguaje de programación.»
    $\rightarrow$ Proposición simple, valor lógico $V$.

1.2 Proposición Compuesta y Conectivos Lógicos

📌 Definición: Proposición Compuesta

Se forma utilizando conectivos lógicos (símbolos o palabras que unen proposiciones simples o modifican su valor de verdad) mediante operaciones como la negación o la combinación de varias proposiciones.

Los ejemplos formales de cada conectivo son: \(\neg p\) (negación), \(p \land q\) (conjunción), \(p \lor q\) (disyunción), \(p \rightarrow q\) (condicional) y \(p \leftrightarrow q\) (bicondicional).

Operación Expresión Símbolo
Negación «No» \(\neg\) o \(\sim\)
Conjunción «Y» \(\land\)
Disyunción «O» \(\lor\)
Condicional «Si \(\dots\), entonces» \(\rightarrow\)
Bicondicional «Si y solo si» \(\leftrightarrow\)

1.3 Valores y Tablas de Verdad

Toda proposición posee un único valor lógico $(V$ o $1$, $F$ o $0)$. Una tabla de verdad muestra todas las combinaciones posibles de valores: para $n$ variables simples existen $2^n$ filas (2 filas para 1 variable, 4 para 2 variables y 8 para 3 variables).

💡 Comportamiento de los Principales Operadores Lógicos
  • Negación $(\neg)$: Invierte el valor de verdad $(V \leftrightarrow F)$.
  • Conjunción $(\land)$: Verdadera únicamente si ambas proposiciones son verdaderas.
  • Disyunción $(\lor)$: Falsa únicamente si ambas proposiciones son falsas.
  • Implicación $(\rightarrow)$: Falsa solo si el antecedente es verdadero $(V)$ y el consecuente es falso $(F)$.
  • Doble implicación $(\leftrightarrow)$: Verdadera si ambas proposiciones tienen el mismo valor lógico.

🧩 Ejemplo 1.2: Aplicación de los Conectivos Lógicos
  • Negación: Si $P$ es «El número 4 es par» $(V)$, entonces $\neg P$ es «El número 4 no es par» $(F)$.
  • Conjunción: «Aprobé cálculo» $(P)$ y «Aprobé física» $(Q)$. Solo es verdadera si pasé ambas materias.
  • Disyunción: «Iré a la biblioteca» $(P)$ o «Estudiaré en casa» $(Q)$. Solo es falsa si no hago ninguna de las dos.
  • Implicación: «Si llueve $(P)$, entonces llevo paraguas $(Q)$». Solo se rompe si llueve $(V)$ y no llevo paraguas $(F)$.
  • Doble implicación: «Un triángulo es equilátero $(P)$ si y solo si todos sus ángulos miden $60^\circ$ $(Q)$».

MÓDULO 02 Proposiciones Lógicas: Clasificación

2.1 Formas Alternativas del Condicional

📌 Estructura del Condicional

En matemáticas, las proposiciones condicionales forman la base de los teoremas:

  • Antecedente $(P)$: Hipótesis o condición suficiente.
  • Consecuente $(Q)$: Tesis o condición necesaria.
$$\underbrace{\text{Hipótesis}}_{\text{Suficiente}} \rightarrow \underbrace{\text{Tesis}}_{\text{Necesaria}}$$

Formas equivalentes en lenguaje natural:
(1) Si $P$, entonces $Q$;
(2) $P$ es condición suficiente para $Q$;
(3) $Q$ es condición necesaria para $P$;
(4) $P$ solo si $Q$;
(5) $Q$ si $P$.

🧩 Ejemplo 2.1: Variaciones Gramaticales del Condicional

Sean $P$: «Una figura es un cuadrado» y $Q$: «La figura tiene cuatro lados». La relación $P \rightarrow Q$ se expresa de 5 maneras equivalentes:

  1. Si una figura es un cuadrado, entonces tiene cuatro lados.
  2. Ser un cuadrado es condición suficiente para tener cuatro lados.
  3. Tener cuatro lados es condición necesaria para ser un cuadrado.
  4. Una figura es un cuadrado solo si tiene cuatro lados.
  5. Una figura tiene cuatro lados si es un cuadrado.

2.2 Tautología, Contradicción y Contingencia

📌 Clasificación según la Última Columna de la Tabla de Verdad
  • Tautología: Resulta verdadera $(V)$ para todas las combinaciones posibles (verdad formal).
  • Contradicción: Resulta falsa $(F)$ para todas las combinaciones posibles (absurdo lógico).
  • Contingencia: Presenta tanto valores verdaderos $(V)$ como falsos $(F)$.

2.3 Implicación Lógica $(\Rightarrow)$ y Equivalencia Lógica $(\equiv)$

Cuando una proposición compuesta resulta en una tautología, la notación de su conectivo principal cambia para reflejar validez universal:

  • Implicación lógica $(\Rightarrow)$: Reemplaza al condicional $(\rightarrow)$ cuando este es el conectivo principal de una tautología.
  • Equivalencia lógica $(\Leftrightarrow$ o $\equiv)$: Reemplaza al bicondicional $(\leftrightarrow)$ cuando este es el conectivo principal de una tautología.

3.3 Ejercicios Resueltos y Propuestos

🧩 Ejemplo 3.1: Simplificación Algebraica Paso a Paso

Simplifique las siguientes 4 expresiones lógicas:

  1. $(A \land B) \to \neg (A \land B)$
  2. $\neg (B \land A) \lor \neg B$
  3. $(A \lor B) \land \neg A$
  4. $A \land (\neg A \lor B) \lor (A \to \neg A)$
🔍 Ver las 4 demostraciones paso a paso

1. $$\begin{aligned} (A \land B) \to \neg (A \land B) &\equiv \neg (A \land B) \lor \neg (A \land B) && (\text{Definición de condicional}) \\ &\equiv \neg (A \land B) && (\text{Idempotencia}) \end{aligned}$$

2. $$\begin{aligned} \neg (B \land A) \lor \neg B &\equiv (\neg B \lor \neg A) \lor \neg B && (\text{Ley de De Morgan}) \\ &\equiv (\neg B \lor \neg B) \lor \neg A && (\text{Asociatividad y Conmutatividad}) \\ &\equiv \neg B \lor \neg A && (\text{Idempotencia}) \end{aligned}$$

3. $$\begin{aligned} (A \lor B) \land \neg A &\equiv (A \land \neg A) \lor (B \land \neg A) && (\text{Ley distributiva}) \\ &\equiv F \lor (B \land \neg A) && (\text{Ley de inversos}) \\ &\equiv B \land \neg A && (\text{Ley de identidad}) \end{aligned}$$

4. $$\begin{aligned} A \land (\neg A \lor B) \lor (A \to \neg A) &\equiv A \land (\neg A \lor B) \lor (\neg A \lor \neg A) && (\text{Definición de condicional}) \\ &\equiv A \land (\neg A \lor B) \lor \neg A && (\text{Idempotencia}) \\ &\equiv (A \land \neg A) \lor (A \land B) \lor \neg A && (\text{Ley distributiva}) \\ &\equiv F \lor (A \land B) \lor \neg A && (\text{Ley de inversos}) \\ &\equiv (A \land B) \lor \neg A && (\text{Ley de identidad}) \\ &\equiv (A \lor \neg A) \land (B \lor \neg A) && (\text{Ley distributiva}) \\ &\equiv V \land (B \lor \neg A) && (\text{Ley de inversos}) \\ &\equiv B \lor \neg A && (\text{Ley de identidad}) \end{aligned}$$

MÓDULO 04 Razonamientos Lógicos

4.1 Inferencia y Validez

Una inferencia es el proceso deductivo para extraer una conclusión a partir de premisas verdaderas. Todo razonamiento vincula sus hipótesis $P_1, \dots, P_n$ con la conclusión $C$ mediante un condicional:

$$\underbrace{(P_1 \land P_2 \land \cdots \land P_n)}_{\text{Premisas}} \rightarrow \underbrace{C}_{\text{Conclusión}}$$

Un razonamiento es válido si dicho condicional es una tautología, e inválido si existe un contraejemplo (premisas verdaderas y conclusión falsa).

4.2 Determinación Analítica de Invalidez

En lugar de construir toda la tabla de verdad, podemos probar la invalidez imponiendo directamente que todas las premisas sean verdaderas $(\equiv V)$ y la conclusión falsa $(\equiv F)$.

🧩 Ejemplo 4.1: Prueba Analítica de Invalidez

Demuestre la invalidez del razonamiento:

$$ \begin{aligned} P_1 &: p \lor q \\ P_2 &: p \\ P_3 &: q \to p \\ P_4 &: \neg q \lor p \\ \therefore \;& q \end{aligned} $$
🔍 Ver resolución y contraejemplo

Imponemos la condición de invalidez:

$$ (P_1, P_2, P_3, P_4 \equiv V) \quad \text{y} \quad (C \equiv F) $$
Primero:

De la conclusión obtenemos inmediatamente:

$$ q \equiv F $$
Luego:

De la premisa \(P_2\) obtenemos:

$$ p \equiv V $$
Finalmente:

Verificamos las demás premisas con \(p \equiv V\) y \(q \equiv F\):

$$ \begin{aligned} P_1 &: p \lor q \equiv V \lor F \equiv V \\[1ex] P_3 &: q \to p \equiv F \to V \equiv V \\[1ex] P_4 &: \neg q \lor p \\ &\equiv \neg F \lor V \\ &\equiv V \lor V \\ &\equiv V \end{aligned} $$

Al existir el contraejemplo \(p \equiv V, q \equiv F\) sin contradicciones, el razonamiento es inválido.

4.4 Reducción al Absurdo

Método indirecto de demostración que incorpora temporalmente la negación de la conclusión $(\neg C)$ como premisa auxiliar. Si al operar con las premisas originales se obtiene una contradicción explícita $(P \land \neg P)$, la conclusión queda validada.

MÓDULO 05 Cuantificadores

5.1 Motivación

La lógica proposicional trata las oraciones como bloques indivisibles, impidiendo expresar generalizaciones o validar argumentos que dependen de la estructura interna de sus sujetos (como el silogismo clásico de Sócrates: «Todos los hombres son mortales; Sócrates es un hombre $\therefore$ Sócrates es mortal»). Para superar esta limitación se introducen los predicados y cuantificadores.

5.2 Predicados y Cuantificadores

📌 Predicado y Universo de Discurso

Un predicado o función proposicional \((P(x), Q(x, y))\) es un enunciado con una o más variables que expresa una propiedad o relación. Adquiere valor de verdad cuando sus variables toman valores en el universo de discurso $U$.

Cuantificador Símbolo Notación Definición formal / Valor de verdad
Universal $\forall$ $\forall x\,(p(x))$ $V$ si $p(x_1) \land p(x_2) \land \dots \land p(x_n)$ es $V$; $F$ en caso contrario.
Existencial $\exists$ $\exists x\,(p(x))$ $V$ si $p(x_1) \lor p(x_2) \lor \dots \lor p(x_n)$ es $V$; $F$ en caso contrario.
Existencial Único $\exists!$ $\exists! x\,(p(x))$ $V$ si $p(x)$ es $V$ para exactamente un $x$; $F$ en caso contrario.
🧩 Ejemplo 5.1: Simbolización en Lógica de Predicados

Simbolice: «Cualquier estudiante de la facultad debe aprobar Cálculo y Matemáticas Discretas».

🔍 Ver formalización simbólica

Primero: Definimos el universo de discurso (\(U\)) como los estudiantes de la facultad.

Luego: Establecemos los predicados correspondientes:

$$ \begin{aligned} ApruebaC(x) &: \text{«}x\text{ aprueba Cálculo»} \\ ApruebaMD(x) &: \text{«}x\text{ aprueba Matemáticas Discretas»} \end{aligned} $$

Finalmente: La formalización de la proposición es:

$$ \forall x \, [ApruebaC(x) \land ApruebaMD(x)] $$

5.3 Negación (Leyes de De Morgan) y Propiedades

📐 Teorema 5.1: Negación de los Cuantificadores (Leyes de De Morgan)
$$ \begin{aligned} \neg\forall x(p(x)) &\equiv \exists x(\neg p(x)) \\[1ex] \neg\exists x(p(x)) &\equiv \forall x(\neg p(x)) \end{aligned} $$
🧩 Ejemplo 5.2: Simplificación de Negaciones Cuantificadas

Sea $U = \mathbb{R}$. Simplifique:
a) $\neg \forall x [x > 3 \rightarrow x^2 > 9]$
b) $\neg \forall x [f(x) = 0 \rightarrow x = 0]$.

🔍 Ver resolución paso a paso

a) $$\begin{aligned} \neg \forall x [x > 3 \rightarrow x^2 > 9] &\equiv \exists x [\neg(x > 3 \rightarrow x^2 > 9)] && \text{(De Morgan para cuantificadores)} \\ &\equiv \exists x [x > 3 \land \neg(x^2 > 9)] && \text{(Negación del condicional)} \\ &\equiv \exists x [x > 3 \land x^2 \le 9] && \text{(Negación del operador } > \text{)} \end{aligned}$$

b) $$\begin{aligned} \neg \forall x [f(x) = 0 \rightarrow x = 0] &\equiv \exists x [\neg(f(x) = 0 \rightarrow x = 0)] && \text{(De Morgan para cuantificadores)} \\ &\equiv \exists x [f(x) = 0 \land \neg(x = 0)] && \text{(Negación del condicional)} \\ &\equiv \exists x [f(x) = 0 \land x \neq 0] && \text{(Negación del operador } = \text{)} \end{aligned}$$

2 Equivalencia $\forall x\,(P(x) \to \neg Q(x))$ $\equiv$ $\neg\exists x\,(P(x) \land Q(x))$
3 Equivalencia $\forall x\,(P(x) \to Q(x))$ $\equiv$ $\neg\exists x\,(P(x) \land \neg Q(x))$
4 Equivalencia $\forall x\,P(x) \to \exists x\,Q(x)$ $\equiv$ $\exists x\,(P(x) \to Q(x))$
5 Equivalencia $\exists x\,(P(x) \lor Q(x))$ $\equiv$ $\exists x\,P(x) \lor \exists x\,Q(x)$
6 Implicación $\forall x\,P(x)$ $\Rightarrow$ $\exists x\,P(x)$
7 Implicación $\forall x\,P(x) \lor \forall x\,Q(x)$ $\Rightarrow$ $\forall x\,(P(x) \lor Q(x))$
8 Implicación $\forall x\,(P(x) \to Q(x))$ $\Rightarrow$ $\forall x\,P(x) \to \forall x\,Q(x)$
9 Implicación $\exists x\,(P(x) \land Q(x))$ $\Rightarrow$ $\exists x\,P(x) \land \exists x\,Q(x)$

5.4 Ejercicios Propuestos

📝 Práctica de Cuantificadores
  1. En $\mathcal{U} = \mathbb{R}$, con $p(x): x^2 - 7x + 10 = 0$ y $y(x): \operatorname{sen}(x) = 0$,
    determine el valor de verdad de $p(2)$, $p(1)$, $y(\pi)$, $y(\pi/2)$,
    así como de $\forall x\,(x^2 \ge 0)$, $\exists x\,(x^2 + 1 = 0)$ y $\exists! x\,(x^2 = 0)$.
  2. Simbolice formalmente:
    «Algunos programadores no toman café»;
    «Existe un número real negativo»;
    «No hay ningún número primo que sea par»;
    «Todos los números enteros son positivos o negativos»;
    «Existe un número natural que es menor o igual que cero»;
    «Todo número real es mayor que 5 o menor que 2».
  3. Simplifique las negaciones en $U = \mathbb{R}$:
    $\neg \forall x [x^2 \ge 0]$,
    $\neg \exists x [x > 0 \land x^2 = 2]$,
    $\neg \exists x [1 < x < 5]$,
    $\neg \exists x [x \neq 1 \land (x < -2 \lor x \ge 4)]$,
    $\neg \forall x [x > 3 \rightarrow x^2 > 9]$,
    $\neg \exists x [f(x) = 0 \land x = 0]$.
  4. Simplifique las negaciones en $U = \mathbb{N}$:
    $\neg \forall x [x + 1 > x]$,
    $\neg \exists x [x^2 = 2]$,
    $\neg \forall x [x \text{ es par} \lor x \text{ es impar}]$,
    $\neg \exists x [x > 0 \land x < 1]$,
    $\neg \forall x [x > 2 \rightarrow x \ge 3]$,
    $\neg \exists x [x \neq 0 \land x^2 = 0]$.
  5. En $\mathcal{U} = \mathbb{Z}$, con $p(x): x \text{ es par}$, $q(x): x > 0$ y $r(x): x \text{ es múltiplo de } 5$, simbolice:
    (a) Todo entero es par o múltiplo de 5;
    (b) Existe un entero positivo y par;
    (c) Si un entero es múltiplo de 5, entonces no es positivo;
    (d) Un entero es par si, y solo si, es positivo;
    (e) No existe ningún entero par que no sea positivo.
