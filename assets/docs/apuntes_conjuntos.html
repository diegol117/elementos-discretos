MÓDULO 01 Definiciones

1.1 Analogía Lógica y Conjuntos Notables

Existe una analogía profunda entre la lógica proposicional y la Teoría de Conjuntos: mientras que la lógica opera sobre proposiciones de verdad, la teoría de conjuntos trabaja sobre colecciones de objetos. Los conectivos lógicos $(\land, \lor, \neg)$ se materializan en operaciones algebraicas entre conjuntos.

📌 Definición: Conjunto

Un conjunto es una colección de objetos bien definidos, llamados elementos, que comparten una característica común o están agrupados bajo un mismo criterio.

🧩 Ejemplo 1.1: Vocales del Alfabeto

El conjunto de las vocales del alfabeto español se escribe por extensión como: $$V = \{a, e, i, o, u\}$$

Antes de estudiar operaciones, es indispensable definir los límites absolutos de cualquier espacio de estudio, vinculados directamente con contradicciones y tautologías de la lógica proposicional:

  • El conjunto vacío representa una contradicción lógica y no contiene elementos.
  • El conjunto universal representa una tautología lógica y contiene todo el marco de referencia.
Conjunto Definición Formal
Vacío \(\emptyset = \{x \mid x \in A \land x \notin A\}\)
Universal \(U = \{x \mid x \in A \lor x \notin A\}\)

1.2 Formas de Definición: Extensión y Comprensión

Para especificar qué elementos forman parte de un conjunto, se emplean dos métodos principales:

  • Por Extensión (o Tabulación): Se enumeran uno a uno los elementos del conjunto: $$A = \{a_1, a_2, \cdots, a_n\}$$
  • Por Comprensión (o Forma Constructiva): Se define mediante una propiedad o función proposicional $P(x)$ sobre un universo $U$: $$A = \{x \in U \mid P(x)\}$$
🧩 Ejemplo 1.2: Conversión a Comprensión y análisis de infinitos

Defina por comprensión los siguientes conjuntos y justifique si es posible representarlos por extensión:

  1. El conjunto de los números naturales impares.
  2. El conjunto de todos los números reales mayores que 5.
  3. El conjunto $B = \{7, 14, 21, 28, 35\}$.
🔍 Ver solución

Primero:

\(I = \{x \in \mathbb{N} \mid x = 2k - 1\}\)

para algún \(k \in \mathbb{N}\).

Luego:

\(M = \{x \in \mathbb{R} \mid x > 5\}\)

Es un conjunto infinito no numerable; es imposible representarlo por extensión.

Finalmente:

\(B = \{x \in \mathbb{N} \mid x = 7k\}\)

con \(k \in \mathbb{N}\) y \(1 \leq k \leq 5\).

🧩 Ejemplo 1.3: De Comprensión a Extensión y Casos Especiales

Exprese por extensión:
$A = \{x \in \mathbb{Z} \mid -2 \leq x < 3\}$
$C = \{x \in \mathbb{R} \mid 3x - 7 = 2\}$
$D = \{x \in \mathbb{R} \mid x^2 + 4 = 0\}$.

🔍 Ver solución
  • $A = \{-2, -1, 0, 1, 2\}$.
  • $3x - 7 = 2 \Rightarrow x = 3$. Es un conjunto unitario: $C = \{3\}$.
  • $x^2 = -4$ no tiene solución en $\mathbb{R}$. Es el conjunto vacío: $D = \emptyset$.

MÓDULO 02 Operaciones y Diagramas de Venn

2.1 Operaciones Aritmético-Lógicas

Cada operación responde directamente a un conectivo lógico:

Operación Definición Formal
Unión $A \cup B = \{x \mid x \in A \lor x \in B\}$
Intersección $A \cap B = \{x \mid x \in A \land x \in B\}$
Diferencia $A - B = \{x \mid x \in A \land x \notin B\}$
Complemento $A^c = \{x \in U \mid x \notin A\}$

2.2 Diferencia Simétrica

📌 Definición: Diferencia Simétrica

Recolecta los elementos que pertenecen exclusivamente a uno de los conjuntos, omitiendo su intersección. Posee dos definiciones equivalentes:

  • Definición I (Por exclusión):
    $A \triangle B = (A \cup B) - (A \cap B)$
  • Definición II (Por unión de diferencias):
    $A \triangle B = (A - B) \cup (B - A)$

2.3 Estudio Visual con Diagramas de Venn y Cardinalidad

📌 Diagramas de Venn

Representaciones gráficas que traducen proposiciones lógicas en regiones espaciales. El rectángulo $U$ delimita el universo, los círculos representan los conjuntos y las regiones sombreadas indican la solución.

🧩 Ejemplo 2.1: Operación Combinada

Sea:
\(U = \{1, \cdots, 10\}\)
\(A = \{1, 2, 3, 4, 5\}\)
\(B = \{4, 5, 6, 7\}\)
\(C = \{2, 4, 8, 9\}\).
Halle por extensión: $$\left[ (A \cup B) - C \right]^c \cap (A \triangle B)$$

🔍 Ver resolución paso a paso
Primero:
\(A \cup B = \{1, 2, 3, 4, 5, 6, 7\}\)
Luego:
\((A \cup B) - C = \{1, 3, 5, 6, 7\}\)
\([(A \cup B) - C]^c = \{2, 4, 8, 9, 10\}\)
Finalmente:
\(A \triangle B = \{1, 2, 3, 6, 7\}\)
Por lo tanto:
\(\{2, 4, 8, 9, 10\} \cap \{1, 2, 3, 6, 7\}\)
\(= \mathbf{\{2\}}\)

Cardinalidad y Principio de Inclusión-Exclusión

El cardinal \(|A|\) es el número de elementos distintos de \(A\). Cuantitativamente, un diagrama de Venn se divide en regiones disjuntas \((x, y, z, w)\):

  • \(x\): elementos exclusivos de \(A\) \((|A - B| = x)\).
  • \(y\): elementos en la intersección \((|A \cap B| = y)\).
  • \(z\): elementos exclusivos de \(B\) \((|B - A| = z)\).
  • \(w\): elementos externos \((|(A \cup B)^c| = w)\).
📐 Teorema: Propiedades de Cardinales
Propiedad Fórmula General
Unión $\begin{aligned} |A \cup B| &= |A| + |B| - |A \cap B| \end{aligned}$
Complemento $\begin{aligned} |A^c| &= |U| - |A| \end{aligned}$
Diferencia $\begin{aligned} |A - B| &= |A| - |A \cap B| \end{aligned}$
Diferencia Simétrica $\begin{aligned} |A \triangle B| &= |A \cup B| - |A \cap B| \\ &= |A - B| + |B - A| \end{aligned}$
🧩 Ejemplo 2.2: Problema Aplicado (Estudiantes universitarios)

En un grupo de 100 estudiantes, 60 programan en Python, 40 asisten a Estructuras Discretas y 20 hacen ambas cosas. Determine:

  1. Estudiantes que programan en Python o asisten a Discretas.
  2. Estudiantes que no realizan ninguna de las dos actividades.
🔍 Ver solución

Sean \(P\) (Python), \(D\) (Discretas) y \(U\) (100).

$$ |P|=60, \ |D|=40, \ |P \cap D|=20 $$
Primero:
$$ \begin{aligned} |P \cup D| &= |P| + |D| - |P \cap D| \\ &= 60 + 40 - 20 \\ &= \mathbf{80}. \end{aligned} $$
Segundo:
$$ \begin{aligned} |(P \cup D)^c| &= |U| - |P \cup D| \\ &= 100 - 80 \\ &= \mathbf{20}. \end{aligned} $$

MÓDULO 03 Familias de Conjuntos

3.1 Familias y Operaciones Generalizadas

📌 Definiciones: Familia, Unión e Intersección Generalizada
  • Familia de conjuntos: Colección cuyos elementos son otros conjuntos.
  • Unión generalizada: Elementos que pertenecen al menos a uno de los conjuntos.
  • Intersección generalizada: Elementos presentes en todos y cada uno de los conjuntos.
Concepto Expresión Formal
Familia de conjuntos $\mathcal{A} = \{A_i\}_{i \in I}$
Unión generalizada $\bigcup_{i \in I} A_i = A_1 \cup \cdots \cup A_n$
Intersección generalizada $\bigcap_{i \in I} A_i = A_1 \cap \cdots \cap A_n$
🧩 Ejemplo 3.1: Cálculo con Índices

Con:

$$ \begin{aligned} I &= \{1, 2, 3\} \\ A_1 &= \{1, 2, 3\} \\ A_2 &= \{2, 3, 4\} \\ A_3 &= \{3, 4, 5\} \end{aligned} $$

Determine la familia \(\mathcal{A}\), su unión e intersección generalizada.

🔍 Ver solución
Primero:
$$ \begin{aligned} \mathcal{A} &= \{ \{1, 2, 3\}, \\ &\quad \{2, 3, 4\}, \\ &\quad \{3, 4, 5\} \}. \end{aligned} $$
Luego:
$$ \bigcup_{i \in I} A_i = \{1, 2, 3, 4, 5\} $$
Finalmente:
$$ \bigcap_{i \in I} A_i = \{3\} $$

3.2 La Familia Potencia (Conjunto Potencia)

📌 Definición: Conjunto Potencia

Es la familia compuesta por todos los subconjuntos posibles de $A$ (incluyendo $\emptyset$ y $A)$. Su cardinalidad cumple el teorema: $$\left| \mathcal{P}(A) \right| = 2^{|A|}$$

🧩 Ejemplo 3.2: Construcción Progresiva del Conjunto Potencia

Determine:

$$ \begin{aligned} \mathcal{P}(V) &\text{ para } V = \emptyset \\ \mathcal{P}(B) &\text{ para } B = \{a\} \\ \mathcal{P}(A) &\text{ para } A = \{a, b\}. \end{aligned} $$
🔍 Ver solución
Primero:
$$V = \emptyset \implies \mathcal{P}(V) = \{\emptyset\}$$
Luego:
$$B = \{a\} \implies \mathcal{P}(B) = \{\emptyset, \{a\}\}$$
Finalmente:
$$ \begin{aligned} A &= \{a, b\} \\ \mathcal{P}(A) &= \{\emptyset, \{a\}, \{b\}, A\} \end{aligned} $$

3.3 La Subfamilia Partición

📌 Definición: Conjunto Partición

Es una familia de subconjuntos no vacíos y mutuamente disjuntos de \(A\) cuya unión es \(A\). Debe cumplir tres reglas:

  1. Exclusión del vacío:
    $$\forall X \in P \Rightarrow X \neq \emptyset$$
  2. Mutuamente disjuntos:
    $$X, Y \in P: X \neq Y \Rightarrow X \cap Y = \emptyset$$
  3. Recubrimiento (Unión):
    $$\bigcup_{X \in P} X = A$$

Para cualquier conjunto no vacío, el cardinal satisface \(1 \leq |P| \leq |A|\).

MÓDULO 04 Producto Cartesiano

4.1 Definición y Representación

📌 Definición: Producto Cartesiano

Es el conjunto de pares ordenados formados por un elemento de $A$ y uno de $B$: $$A \times B = \{(a, b) \mid a \in A \land b \in B\}$$ El orden importa $((a, b) \neq (b, a))$; por tanto, no es conmutativo $(A \times B \neq B \times A)$. No se grafica en diagramas de Venn, sino en un plano cartesiano.

🧩 Ejemplo 4.1: Cálculo de Producto Cartesiano

Sean:
$A = \{1, 2\}$
$B = \{a, b, c\}$.
Halle $A \times B$ y su cardinalidad.

🔍 Ver solución
Primero:
$$ \begin{aligned} A \times B = \{ &(1, a), (1, b), (1, c), \\ &(2, a), (2, b), (2, c)\} \end{aligned} $$
Luego:
$$ |A \times B| = |A| \cdot |B| = 2 \cdot 3 = \mathbf{6}. $$

4.2 Propiedades del Producto Cartesiano

Propiedad Expresión Formal
No conmutatividad $A \times B \neq B \times A$
No asociatividad $(A \times B) \times C \neq A \times (B \times C)$
Elemento absorbente $A \times \emptyset = \emptyset \times A = \emptyset$
Distributividad (Unión) $A \times (B \cup C) = (A \times B) \cup (A \times C)$
Distributividad (Intersección) $A \times (B \cap C) = (A \times B) \cap (A \times C)$

MÓDULO 05 Relaciones e Inclusión

5.1 Subconjunto e Igualdad

Concepto Definición Formal
Subconjunto (Inclusión) $A \subseteq B \iff (\forall x)(x \in A \Rightarrow x \in B)$
Subconjunto propio $A \subset B \iff (A \subseteq B \land A \neq B)$
Igualdad de Conjuntos $A = B \iff (A \subseteq B \land B \subseteq A)$

5.2 Teoremas bajo Hipótesis de Inclusión \((A \subseteq B)\)

📐 Teoremas de Inclusión
  • Unión:
    $$A \subseteq B \iff A \cup B = B$$
  • Intersección:
    $$A \subseteq B \iff A \cap B = A$$
  • Diferencia:
    $$A \subseteq B \Rightarrow A - B = \emptyset$$
  • Universo:
    $$A \subseteq B \Rightarrow A^c \cup B = U$$

5.3 Estrategias y Esquemas de Demostración

Para demostrar teoremas algebraicos de conjuntos, se introduce un elemento arbitrario $x$ y se aplican reglas de inferencia lógica basadas en los 4 casos estructurales de hipótesis y tesis:

Caso Forma General Objetivo Esquema de Demostración
1 \((C_1 \subseteq C_2) \Rightarrow (C_3 \subseteq C_4)\) Inclusión:
\(C_3 \subseteq C_4\)
1.   \(C_1 \subseteq C_2\) 2.   \(x \in C_3\)
∴   \(x \in C_4\)
2 \((C_1 \subseteq C_2) \Rightarrow (C_3 = C_4)\) Dos inclusiones:
\(C_3 \subseteq C_4\) y \(C_4 \subseteq C_3\)
i) 1.   \(C_1 \subseteq C_2\) 2.   \(x \in C_3\)
∴   \(x \in C_4\)
ii) 1.   \(C_1 \subseteq C_2\) 2.   \(x \in C_4\)
∴   \(x \in C_3\)
3 \((C_1 = C_2) \Rightarrow (C_3 \subseteq C_4)\) Inclusión:
\(C_3 \subseteq C_4\)
1.   \(C_1 \subseteq C_2\) 2.   \(C_2 \subseteq C_1\) 3.   \(x \in C_3\)
∴   \(x \in C_4\)
4 \((C_1 = C_2) \Rightarrow (C_3 = C_4)\) Dos inclusiones:
\(C_3 \subseteq C_4\) y \(C_4 \subseteq C_3\)
i) 1.   \(C_1 \subseteq C_2\) 2.   \(C_2 \subseteq C_1\) 3.   \(x \in C_3\)
∴   \(x \in C_4\)
ii) 1.   \(C_1 \subseteq C_2\) 2.   \(C_2 \subseteq C_1\) 3.   \(x \in C_4\)
∴   \(x \in C_3\)

Nota: El símbolo \(\therefore\) (por lo tanto) indica la conclusión lógica a la que se debe llegar.

🧩 Ejemplo 5.1: Demostración Formal

Demuestre que si $A \subseteq B$, entonces $A \cap A \subseteq B \cap A$ utilizando una tabla deductiva.

🔍 Ver demostración detallada
Paso Proposición Justificación
1 $x \in A \Rightarrow x \in B$ Hipótesis (Def. de $A \subseteq B)$
2 $x \in A \land x \in A$ Nueva hipótesis $(x \in A \cap A)$
3 $x \in A$ Idempotencia en (2)
4 $x \in B$ Modus ponens en (1) y (3)
5 $x \in B \land x \in A$ Conjunción entre (3) y (4) $(\therefore x \in B \cap A)$

MÓDULO 06 Álgebra de Conjuntos y Leyes

6.1 Demostraciones sin Hipótesis

Para demostrar igualdades de conjuntos sin hipótesis, se parte del lado izquierdo y mediante equivalencias lógicas $(\iff)$ se llega al lado derecho.

6.2 Compendio de Leyes del Álgebra de Conjuntos

Ley / Propiedad Variante con Unión $(\cup)$ Variante con Intersección $(\cap)$
Conmutativa $A \cup B = B \cup A$ $A \cap B = B \cap A$
Asociatividad $A \cup (B \cup C) = (A \cup B) \cup C$ $A \cap (B \cap C) = (A \cap B) \cap C$
Distributiva $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
Absorción $A \cup (A \cap B) = A$ $A \cap (A \cup B) = A$
De Morgan $(A \cup B)^c = A^c \cap B^c$ $(A \cap B)^c = A^c \cup B^c$
Idempotencia $A \cup A = A$ $A \cap A = A$
Identidad $A \cup \emptyset = A$
$A \cup U = U$		 $A \cap U = A$
$A \cap \emptyset = \emptyset$
Complementación $A \cup A^c = U$ $A \cap A^c = \emptyset$
Doble Complemento $(A^c)^c = A$ —

6.3 Simplificación Algebraica y de Cardinales

🧩 Ejemplo 6.1: Simplificación de Expresiones

Reduzca la expresión $(A \cup B)^c \cap A$ justificando cada paso algebraico.

🔍 Ver solución

$$\begin{aligned} (A \cup B)^c \cap A &= (A^c \cap B^c) \cap A && \text{(Ley de De Morgan)} \\ &= (A^c \cap A) \cap B^c && \text{(Conmutativa y Asociatividad)} \\ &= \emptyset \cap B^c && \text{(Ley de Inversos: } A^c \cap A = \emptyset \text{)} \\ &= \emptyset && \text{(Ley de Dominación)} \end{aligned}$$
